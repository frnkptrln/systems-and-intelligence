# When Does a Collection Become an Agent?

**Status:** exploratory note — not a repository claim

A collection should not count as an agent merely because its parts coordinate, share memory, or produce a coherent trace. A stronger transition may occur when prediction and control can no longer be usefully localized in the components under a declared state description, and a collective variable gains predictive or interventionally useful structure of its own.

Takashi Ikegami's work on non-trivial information closure (NTIC) provides one candidate language for locating where predictive organization resides. The published Tetrahymena result is narrower than a general collective-agency claim: it studies situated individual autonomy inside a coupled community. The stronger move toward synergy-dominated collective prediction remains a hypothesis to test rather than an established result.

The open question is therefore not whether a system is "really" irreducible. It is: **under which coarse-graining, task, intervention set, and resource budget does the collective description outperform component-wise alternatives?**
