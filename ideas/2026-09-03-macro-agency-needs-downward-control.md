# Macro Agency Needs Downward Control

**Status:** exploratory note — not a repository claim

A macro-description can be useful without being an agent. Population averages, cluster labels, and latent summaries may predict a system while remaining passive descriptions of microdynamics.

A stronger test for macro-agency is intervention. If a macrovariable represents a real control organization, changing that variable through a realizable mechanism should alter later local trajectories in a way that is not captured by a matched micro-level baseline. Michael Levin's work on morphogenesis motivates this distinction: cellular collectives can regulate toward large-scale anatomical targets, but the repository should translate that biological language into an explicit causal model rather than importing "downward causation" as a conclusion.

The useful question is therefore: **does the macrostate add control, or only compression?**

A convincing result would require a declared macrovariable, an intervention that can change it, matched micro perturbations, and held-out predictions about local consequences. Without that separation, collective agency and downward causation remain redescriptions.
