# The Teacher Is Part of the Environment

**Status:** Exploratory note — not a repository claim.

**Trigger.** Chen & Zhou (2026), *WCM: World-Cognition Model for Generalizable Human-Robot Interaction*, arXiv:2607.22999.

Interactive learning complicates the usual decomposition of agent and environment. If a human observes an agent, corrects it, teaches a procedure, and thereby changes the agent's future policy, the human is not merely an evaluator outside the system. During learning, the teacher participates in the transition dynamics that produce future competence.

This suggests a distinction between **supervision as measurement** and **supervision as coupling**. The first evaluates an already defined process; the second changes the process through interaction history.

**Open question.** When does a teacher cease to be an external verifier and become part of the effective runtime or world model? The distinction matters for claims about autonomy, latent competence, and where explanatory credit for successful behavior should be assigned.
