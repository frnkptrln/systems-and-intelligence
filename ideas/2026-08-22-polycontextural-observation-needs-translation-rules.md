# Polycontextural Observation Needs Translation Rules

**Status:** Exploratory note — conceptual connection, not a repository claim or formal implementation.

**Trigger.** The discussion of polycontexturality, with Gotthard Günther's [*Life as Poly-Contexturality*](https://www.vordenker.de/ggphilosophy/la_poly.htm) as historical context.

Several observers can produce descriptions that are locally valid within different identification regimes yet cannot be collapsed into one global description without loss. In this repository, that possibility matters less as a metaphysical thesis than as a measurement warning: disagreement may arise from different interventions, accessible variables, or identity criteria rather than from one observer simply being wrong.

The operational question is what translation rule would allow claims from one observational context to constrain another. Such a rule should state preserved invariants, lost distinctions, and tests that could expose incompatibility. Active Identifiability is one concrete place to examine that question because query selection changes which candidate mechanisms remain equivalent.

The note does not infer consciousness, inner experience, metaphysical identity, or free will from observer-relative descriptions.
