# Polycontextural Observation

**Status:** Reading note and external-anchor mapping — no new result of this repository.
**Origin:** [Polycontextural Observation Needs Translation Rules](../../ideas/2026-08-22-polycontextural-observation-needs-translation-rules.md) (ideas note, 2026-08-22).
**External anchor:** Gotthard Günther, *Life as Poly-Contexturality*, as cited in the ideas note ([vordenker.de](https://www.vordenker.de/ggphilosophy/la_poly.htm)). This note takes the anchor as historical context only, in the way the ideas note does; it does not reconstruct Günther's system, and it makes no claim that any part of the repository implements it.

## What the ideas note keeps

The ideas note keeps one thing from the polycontextural discussion and drops the rest. What it keeps: several observers can produce descriptions that are locally valid within different identification regimes and cannot be collapsed into one global description without loss. What it drops: any inference from that fact to consciousness, inner experience, metaphysical identity, or free will. What it turns the remainder into: a measurement warning. Disagreement between observers may come from different interventions, different accessible variables, or different identity criteria, rather than from one observer being wrong.

The note's operational question is what a *translation rule* between two observational contexts would have to state: the invariants it preserves, the distinctions it loses, and the tests that could expose incompatibility.

## Where the repository already has the pieces

Each element of that question has a home in the repository. The mapping is the content of this note; none of the homes is changed by it.

| Element of the translation rule | Repository anchor | What the anchor supplies |
|:---|:---|:---|
| Descriptions valid only within an identification regime | [Invariance and Identity](../core/invariance-and-identity.md) | Identity as persistence under a declared transformation group; "the same" is regime-relative by construction |
| The observer's access decides what can be witnessed | [The Witness Principle](../core/the-witness-principle.md) | Witnesses exist only inside an access geometry; the [identification register](../../meta/repository-meta/identification-claims.md) carries this as a claim with artifacts |
| Observation changes what remains equivalent | [Measurement as Weak Intervention](../core/measurement-as-weak-intervention.md) | Measurement is itself a small intervention on the observed process |
| Query choice changes the surviving equivalence class | [Active Identifiability](../../lab/experiments/active_identifiability/README.md) | A frozen protocol (no model calls authorized) in which query selection, not more data, decides which candidate mechanisms stay indistinguishable |
| Two observers, one environment, different worlds | [The Same World Is Not the Same World](../../ideas/2026-07-23-the-same-world-is-not-the-same-world.md) | The ideas-level statement that shared data does not give shared structure, and that cooperation needs partial overlap, not identity |
| A worked translation rule with exact accounting | [Representation and Reconstruction Difficulty](../../lab/experiments/representation_reconstruction/README.md) | Under an invertible re-encoding of a trace, the reconstructor's answer is the conjugate rule; the conjugation map is the translation rule, class size the preserved invariant; under a lossy encoding no translation rule exists and contradictions appear |

The last row is the nearest thing the repository has to the note's question in executable form. It is a toy: two "observers" that receive the same process under two encodings, and a closed-form rule that carries claims from one to the other. It says nothing about observers whose regimes differ in what they can intervene on, which is where the ideas note locates the interesting cases.

## What would move this beyond a reading note

Three things, none of which this note does:

1. A statement, for one declared pair of observation channels on one declared process family, of the preserved invariants and lost distinctions of the map between them, in the vocabulary of the [concept registry](../../meta/repository-meta/concept-registry.md) (readout, access geometry, target equivalence).
2. A test that could show two locally valid descriptions to be incompatible rather than merely different, in the sense the identification register uses for a failure condition.
3. A case in which query selection under one channel changes the equivalence class visible under the other, which the Active Identifiability protocol could measure once its execution is authorized.

Until one of these exists, "polycontextural" remains, in this repository, a name for a measurement warning that other pages already state in their own terms.

## Not claimed

- That Günther's polycontexturality is implemented, formalized, or endorsed here.
- That observer-relative descriptions imply anything about consciousness, experience, or identity in the metaphysical sense.
- That the representation experiment's conjugation rule generalizes beyond invertible re-encodings of one finite process family.
