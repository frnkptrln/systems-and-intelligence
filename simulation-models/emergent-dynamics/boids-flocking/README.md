# 🐦 Boids – Emergent Collective Motion

This simulation implements **Craig Reynolds' Boids model** (1987):
each agent follows three simple local rules, and complex flock-like
motion emerges without any central control.

---

## 🧠 Idea

Every boid perceives only its nearby neighbours and applies three
steering forces:

| Rule | Effect |
|:-----|:-------|
| **Separation** | Steer away from neighbours that are too close |
| **Alignment** | Match heading with nearby neighbours |
| **Cohesion** | Steer toward the average position of nearby neighbours |

No boid knows the shape of the flock. Yet the swarm self-organises
into coherent, fluid formations – splitting around obstacles, merging
again, and flowing like a living organism.

### Comparison with Stigmergy Swarm

| | Stigmergy (ants) | Boids (flocking) |
|:---|:---|:---|
| Communication | **Indirect** (pheromone) | **Direct** (local sensing) |
| Goal | Path optimisation | Collective motion |
| Memory | External (environment) | None (stateless) |
| Structure | Trails and networks | Dynamic formations |

Both models produce global order from local rules – but via
fundamentally different coordination mechanisms.

## 🖼 Visualisation

The matplotlib window shows:

- **Coloured dots** – each boid, colour-coded by heading (HSV hue =
  flight angle) so aligned sub-flocks share a colour
- **Faint trails** – recent trajectory of each boid
- **Dark background** – simulates a night-sky aesthetic

The world is toroidal (wrap-around edges).

Press `ESC` to exit.

---

## 🔗 Connection to System Intelligence

- **Regulation (R):** The flock maintains cohesion (a target variable)
  without any explicit set-point
- **Adaptive Capacity (A):** When the flock is disrupted, it reforms
  dynamically – no recovery plan needed
- **Emergent structure:** Global formations are not prescribed by any
  individual rule

## ▶ Run

```bash
cd simulation-models/emergent-dynamics/boids-flocking
python3 boids.py
```

Population, seed, and duration can be selected without editing the source:

```bash
python3 boids.py --boids 80 --seed 7 --steps 1000
```

### Reproducible runs without a window

```bash
python3 boids.py --headless --boids 150 --seed 42 --steps 200 \
  --sample-every 10 --output build/boids-seed-42.json
```

Headless mode requires only NumPy. Without `--output`, JSON goes to stdout.
Existing output files are refused, so comparisons use distinct filenames.
The `boids-run/1` record contains the seed, population, step count, all steering
parameters, Python/NumPy versions, source SHA-256, sampled observables, and final
positions/velocities. Step zero and the last step are always sampled; zero-step
runs are supported. Exact replay is checked in the same software environment,
not promised across NumPy versions or hardware.

`mean_speed` and `maximum_speed` use the simulation's coordinate units per
step. `polarization` is the magnitude of the mean unit heading (0–1); stationary
boids contribute zero. These describe this simulation and are not measurements
of agency, intelligence, or real animal behaviour.

### Toroidal dynamics correction

Runs identify their dynamics as `boids-torus-v2`. Two defects in the original
demonstration are corrected:

- An empty neighbourhood contributes no steering force. Previously all three
  rules subtracted the boid's velocity even when there were no neighbours,
  slowing an isolated boid from speed 1.0 to 0.55 in one step.
- Cohesion averages the shortest local displacement to each neighbour. Averaging
  absolute wrapped positions previously pulled some groups toward the middle
  of the world when neighbours actually straddled an edge.

Old seed trajectories therefore change. No historical benchmark, paper result,
or frozen research artifact is regenerated by this change. The visible demo
keeps its original parameters and appearance. Closing its window now exits the
loop as well as pressing Escape.

From the repository root, `pytest tests/test_boids.py -q` checks isolated motion,
empty neighbourhoods, seam direction, invariance under translating the whole
flock around the torus, finite coincident positions, speed bounds, reproducible
exports, observation endpoints, and refusal to overwrite existing output.

### Experiment ideas

- Increase `W_SEPARATION` to 4.0 → the flock dissolves into loose gas
- Decrease `R_COHESION` to 5.0 → many small sub-flocks instead of one
- Set `NUM_BOIDS = 500` for dramatic large-flock dynamics (slower)
- Try `MAX_SPEED = 4.0` for fast, chaotic motion
